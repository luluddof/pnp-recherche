Context. Two October 2026 preprints (OpenAI "The Exponential Time Hypothesis Is False"; Claude/Anthropic "A 2^{o(n)} Time Algorithm for 3-SAT") claim 3-SAT in 2^{O(m/√log m)} (m clauses; in n variables 2^{O(n loglog n/√log n)}, and 2^{O(n/√log n)} at bounded density). The "ladder": step 1 = 2^{n/√log n} (reached by them), step 2 = 2^{n/log n}, step 3 = 2^{n^{1−ε}}, …, polynomial.

What 25 generations of agents established (main facts):
- Both algorithms follow one law: per-level gain = (number of label directions)^{-1/2}. Recursion, hybrids, better precision, characteristic p, instance-adaptivity, k-Clique / Marx / asymptotic-rank-conjecture routes: no exponent gain (several are proved obstructions).
- Claude's algorithm: running time 2^{O(m/(log m)^{α'})}, α' = log₂(1/ρ), per-level gain ρ = 1/√2 now. ρ is governed by the "crossing trade-off": the swap X(x,y,u,v) = [x=v][y=u] on [N]^4 written as R + C with rank R ≤ p and C a sum of q tensor products (operator-Schmidt rank ≤ q). 4ρ = sup over the curve of (θ + T), p = N^θ, q = N^T. Best curve: Appendix B's "circle" θ² + T² = 4 (balanced p = q = N^{√2}); this is Naslund's Problem 12 / a Hurwitz-type sums-of-squares problem. A curve near the "line" θ + T = 2 would give ρ → 1/2 = step 2. Any ρ < 1/√2 (e.g. 2/3) raises the power of log in the exponent (0.585 for ρ = 2/3).
- Proved (Lean): the line p·q ≥ (2/9)N² (Theorem C, apparently new); in the "monomial model" (signed partial permutations, equivalent to Hrubeš–Wigderson–Yehudayoff intercalate matrices) a stronger bound p²q ≳ N⁴/8, balanced ≥ N^{4/3}/2. Barrier (Theorem B): rank methods cannot go beyond the line. Cardy barrier: every FIXED vertex algebra gives ≥ √2. No low-degree polynomial equation separates the swap at N = 3 (degree ≤ 7).
- Failed constructions: ~15 families (Clifford, Pauli, groups, Paley, Cayley–Dickson/sedenions, Hrubeš's pieces (curve θ = 1+2H(b), T = 1+2H(0.110−b), outside the circle), vertex-algebra modules, group-invariant monomial arrays (anisotropy obstruction)). Small-size gains always disappeared (the sizes 1, 2, 4, 8 are special: b(N) ≈ N up to N = 8, jump at N = 9).
- Exact small values b(N) (least balanced p): 1, 3, 4, 6, 7, 8, 8 for N = 2..8 (border: 3, 5, 6 for N = 4, 5, 6); N = 9: 11..14.
- FINITE-SIZE FACT: Appendix B's construction is TRIVIAL (b = N²) for N ≤ 256 and its exponent drops below 1.6 only near N ≈ 10^12; Hrubeš's pieces beat it up to N ≈ 2^40; direct sums of 8×8 Hurwitz blocks give N²/8. So at realistic sizes the algorithm as written gains nothing from Appendix B.
- OpenAI side (Appendix D, tensor contraction with 2-adic precision): root-dominated recursion; constants: precision factor κ = 24 in the paper vs optimum ≈ 2–5.9 (black-box precision optimal up to ≈12); modes 4× redundant (factor 2 in the exponent); optimal taper 1/√3 of the exponent; total constant gain estimated ≈ 1/5 of the exponent, unverified. A mod-3 evaluator improves the interpolation route by a loglog factor (decision only; dominated by the headline).
- Random 3-CNF refutation: the 2026 algorithms are best only for density Δ ≤ c·log n; central obstacle unchanged.
